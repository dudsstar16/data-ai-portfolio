# Controle de execução do portfólio

- Leia a memória rápida e o histórico conforme o AGENTS.md. Consulte só os arquivos e os trechos necessários para o objetivo.
- Ao iniciar um objetivo, indique modelo disponível, esforço, motivo e como verificar que terminou. Reutilize a configuração já aprovada quando ela servir. Pause antes de qualquer troca de modelo ou esforço e espere Eduarda confirmar a configuração escolhida no app.
- Considere Sol com esforço baixo para mudanças pequenas e médio para implementação com integração e testes. Considere Terra quando a inspeção visual dominar. Recomende esforço alto ou um modelo mais forte apenas se houver uma dificuldade concreta que compense o custo.
- A cada ação, agrupe leituras compatíveis, limite saídas e elimine consultas repetidas. Aprove cada troca uma vez, mantendo as ações seguintes na configuração escolhida.
- Divida objetivos grandes em entregas verificáveis para administrar a janela de cinco horas. Use os dados de uso somente quando a interface os expuser. Sem telemetria, descreva o consumo provável qualitativamente e evite prometer duração ou saldo. A troca de configuração é feita pela usuária.
- Encerre com as verificações aplicáveis ou com o bloqueio concreto e o que ainda falta.
